\# AGENTS.md



Este repositório documenta a avaliação técnico-metodológica da viabilidade de adaptação do Monitor do Sistema Prisional SP para o Rio Grande do Sul.



\## Regra central



O repositório `MonitorPrisional2024` é fonte de inspeção. Não modificar, não commitar e não fazer push nesse repositório sem autorização explícita.



\## Objetivos



1\. Inventariar scripts, dados, dependências e documentação do Monitor SP.

2\. Identificar quais fontes de dados são específicas de SP.

3\. Mapear equivalentes possíveis para o RS.

4\. Identificar lacunas de dados.

5\. Avaliar viabilidade técnica, metodológica e institucional.

6\. Propor roteiro de adaptação para o RS.



\## Onde salvar



\- Notas sobre o repositório SP: `docs/inventario\_repositorio\_sp.md`

\- Fontes usadas no projeto SP: `docs/fontes\_dados\_sp.md`

\- Fontes disponíveis para o RS: `docs/fontes\_dados\_rs.md`

\- Lacunas do RS: `docs/lacunas\_dados\_rs.md`

\- Diagnóstico de viabilidade: `docs/diagnostico\_viabilidade\_rs.md`

\- Scripts exploratórios: `scripts/exploratory/`

\- Scripts de adaptação para RS: `scripts/rs/`

\- Tabelas derivadas: `outputs/tabelas/`



\## Restrições



\- Não copiar código do repositório SP para este repositório sem necessidade e autorização.

\- Não alterar dados brutos manualmente.

\- Não subir bases brutas grandes.

\- Diferenciar fatos observados no repositório SP de inferências sobre viabilidade no RS.
